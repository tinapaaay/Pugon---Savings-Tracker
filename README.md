# Pugon

A cozy gamified savings tracker where every financial goal becomes a recipe for a future dream.

Pugon means “traditional oven” in Filipino. Instead of using plain progress bars only, this project makes saving feel more meaningful: each contribution becomes an ingredient, milestones show recipe stages, and completed goals are “fresh from the oven.”

## Features

- Create custom savings goals and recipe names
- Add savings contributions to each goal
- Track current savings, target amount, and percentage progress
- Recipe-inspired milestone messages at 25%, 50%, 75%, and 100%
- Starter goals for a MacBook fund, emergency fund, and motorcycle fund
- Delete goals you no longer need
- Reset to the starter demo goals
- Automatically saves data with `localStorage`
- Responsive layout for mobile and desktop
- Accessible dialogs, buttons, labels, and progress bars

## Project Concept

This project uses the theme:

> Savings for the life you are baking.

Examples of dream recipes include:

- **Creative Loaf** for a MacBook fund
- **Safety Pandesal** for an emergency fund
- **Roadtrip Croissant** for a motorcycle fund

The game elements are designed to encourage progress without punishing users for saving slowly.
